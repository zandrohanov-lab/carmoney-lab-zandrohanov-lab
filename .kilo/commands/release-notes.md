---
description: "Подготовить письмо заказчику о последних изменениях"
---

1. Спроси у пользователя диапазон коммитов для сбора release notes. Если диапазон не указан, используй последние 5 коммитов.
2. Проверь, есть ли готовый release notes. Если его нет, подготовь письмо заказчику по выбранному диапазону коммитов, используя скилл `.kilo/skills/release-notes`.
3. Спроси у пользователя email-адрес, на который нужно подготовить файл письма.
4. Сформируй тело письма по шаблону `.kilo/skills/release-notes/mail-template.md`.
5. Сформируй локальный файл письма через `bash scripts/create_email.sh <email> <тело> <вложение> [файл .eml]`.
6. Создай запись в `docs/release-notes/sent/` с email получателя и путём к подготовленному файлу.
7. Сделай trace работы этой команды в `docs/release-notes/trace/`.

Ограничения:

- Изменяй только файлы, относящиеся к release notes, журналу отправленных писем и trace этой команды.
- Не создавай коммиты.
- Не отправляй данные на сервер.
- Не получай и не обновляй данные репозитория с сервера.
