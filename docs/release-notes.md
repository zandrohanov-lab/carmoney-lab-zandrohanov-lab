# Release notes — carmoney-lab

Дата: 2026-10-10
Версия/релиз: v0.4 (эпики 1.x «День 1», ДЗ.1 «MILEAGE», 2.1.1–2.1.4 «Инструменты»)

## Что изменилось

Добавлено бизнес-правило по пробегу: заявки с пробегом ≥ 400 000 км, которые по LTV получили бы `approve`, теперь уходят в ручное ревью с `approved_limit = 0`. Граница строгая: `399 999` — ещё `approve`, `400 000` и выше — `review`. Поле `mileage` стало обязательным: отсутствие ключа, `null` или пустая строка дают 422 с указанием поля. Валидационный потолок `500 000` км сохранён.
**Задача:** hw1/dz1 — Правило по пробегу — PR #7
**Эпик:** ДЗ.1 «MILEAGE» (ветка `hw1/dz1-zandrohanov-lab`)
**Исполнитель:** z.androhanov
