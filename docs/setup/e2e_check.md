# E2E-проверка формы заявки через Playwright

Дата прогона: 2026-10-10.
Сервис: `http://localhost:8080` (health: 200).
Браузер: Chromium через Playwright.

## Сценарий: пробег 400 001 км

Цель: убедиться, что аномально большой пробег обрабатывается системой, и зафиксировать реакцию UI скриншотом.

### Шаги

1. Открыл `http://localhost:8080`. Заголовок страницы дословно:
   `Предварительная оценка заявки — carmoney-lab`.
   Под заголовком параграф: `Учебный сервис. Все данные синтетические, реальные заявки сюда вводить нельзя.`
   Форма уже заполнена значениями по умолчанию:
   - Идентификатор клиента: `CL-0025`
   - VIN: `XTA21099998765432`
   - Год выпуска: `2019`
   - Пробег, км: `84000`
   - Оценочная стоимость, ₽: `900000`
   - Запрошенная сумма, ₽: `450000`
   - Срок, месяцев: `24`

2. В поле `Пробег, км` ввёл `400001` (заменил `84000`).

3. Нажал кнопку `Отправить заявку`.

### Что показала система (дословно из DOM после отправки)

В форме поле `Пробег, км` содержит `400001`, остальные поля без изменений.

Под формой появился блок с заголовком `Решение` и парами терм/определение:

- Решение: `review`
- LTV: `50 %`
- Возраст авто: `7 лет`
- Одобренный лимит: `0 ₽`
- Номер заявки: `27`

### Артефакты

- Скриншот результата: `docs/setup/screenshots/e2e_mileage_400001.png` (full page, PNG).

### Что не удалось / не делалось

- Не делал отдельных прогонов с другими пробегами в рамках этой задачи — только один прогон с `400001` по запросу.
- Сетевые ответы backend не снимал — фиксировал только то, что показала страница.

## Сценарий: невалидный пробег 500 001 км

Дата прогона: 2026-10-10.

### Шаги

1. Открыл `http://localhost:8080` в Chromium через Playwright.
2. В поле `Пробег, км` заменил значение `84000` на `500001`.
3. Нажал `Отправить заявку`.

### Результат

- Сервер вернул `422 Unprocessable Entity`.
- Интерфейс показал блок `Заявка не принята`.
- В блоке отображается ошибка: `mileage: Пробег от 0 до 500000 км`.
- Проверка пройдена: пользователь видит допустимый диапазон пробега после отправки невалидного значения.

### Артефакт

- Скриншот: `docs/setup/e2e_invalid_mileage.png` (full page, PNG).
