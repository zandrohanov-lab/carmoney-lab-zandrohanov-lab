## Что изменилось

Регламент описания Pull Request зафиксирован в `.kilo/rules/pr-rules.md`: каждое описание PR обязано содержать четыре раздела — «Что изменилось», «Что проверили», «Чего сознательно не делали», «Изменения структуры СУБД и необходимость миграции». Без этих разделов PR не открывается; если запрос пользователя им противоречит, агент обязан сообщить о нарушении и уточнить вариант оформления.
